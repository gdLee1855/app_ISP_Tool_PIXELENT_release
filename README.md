# PIXELENT ISP Tool - releases

PIXELENT ISP Tool 배포 파일 (exe) 저장소입니다. 프로그램은 켤 때 이곳의 최신 Release 를 확인해 업데이트를 안내합니다.
Release binaries of PIXELENT ISP Tool. The tool checks the latest release here at start and offers to update.

- PIXELENT_ISP_Tool_x64.exe / PIXELENT_ISP_Tool_x86.exe : 64비트 / 32비트 Windows
